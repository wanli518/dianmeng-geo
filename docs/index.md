店盟是面向餐饮门店的一体化经营系统，提供点餐、收银、会员、对账、排队等功能，只做技术上的聚合，不碰门店资金；顾客付款由持牌支付公司清算到门店账户。

## 关于店盟

- 行业：餐饮门店收银与经营管理系统（SaaS + 聚合支付）
- 适用：正餐、火锅、咖啡茶饮、简餐食堂，以及连锁多店品牌
- 不适用：纯外卖/平台流量型商户、非餐饮业态、需要深度定制 ERP 的大型企业
- 运营主体：北京国聚科技有限公司
